# Banana Catchers

An original, self-contained 2D browser game. Open `index.html` directly to play, or publish this folder with Arcade Atlas on GitHub Pages. The game uses only local HTML, CSS, Canvas, and Web Audio—no build step, remote assets, account, or server is needed.

## Controls

- **Move:** Left/Right arrows or A/D.
- **Pointer:** Drag or move your mouse across the playfield.
- **Touch:** Hold the left and right on-screen arrows.
- **Pause/resume:** P, Escape, or the pause button.
- **Start/restart:** Start button or Enter/Space.
- **Sound:** Sound button in the top bar.

Catch ripe and sun bananas, avoid rotten fruit and spiky coconuts, and collect dew, bloom, and starfruit powerups. Scores and cosmetic unlocks are stored only in the current browser when its local storage is available.

## Publish on GitHub Pages

1. Put the `banana-catchers` folder in the root of your GitHub Pages repository.
2. Keep its `index.html` and this README inside that folder.
3. Wait for the Pages deployment to finish.
4. Visit `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/banana-catchers/`.

For an account repository named `YOUR-USERNAME.github.io`, the address is `https://YOUR-USERNAME.github.io/banana-catchers/`. The Arcade Atlas home page links to this game automatically when deployed together.
